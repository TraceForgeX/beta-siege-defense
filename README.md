Project Title: Beta Siege Defense — 2D Browser-Based Siege Defense Game

Overview: Beta Siege Defense is a 2D browser-based siege defense strategy game where players build turrets, command elemental cannons, raise an army, and hold the fortress against escalating undead hordes. Fully playable instantly in modern browsers (Chrome, Firefox, Edge) with zero downloads required.

Play Live: https://beta-siege-defense.lovable.app/

Project Status: Phase 2 Beta
The project is actively iterated in the open, with core systems deployed and continuous updates driven by player and developer feedback.

Implemented Features & Architecture:
1. Core Game Loop & Logic: Built using Vanilla JavaScript to manage real-time wave progression, entity rendering, collision detection, and scoreboards.
2. Interactive Menus & UI: Fully functional in-game menus, dynamic wave displays, and progression tracking systems.
3. Economy & Store Systems: Integrated crystal-gold exchange store and army purchase store for tactical resource management.
4. Defense Arsenal: Deploy archers, catapults, flame throwers, and lightning towers against incoming threats.
5. Enemy Hordes: Face diverse foes across 50 grueling waves, from basic plant zombies and fast spiders to armored skeletons, creepers, and the final Bone King boss.

Tech Stack:
1. Frontend Logic: Vanilla JavaScript (Game loop, wave logic, state management, UI interactions).
2. Styling & Layout: CSS & HTML structure.
3. Hosting & Delivery: Instant browser deployment via Lovable.

This is an open beta project. Feedback, bug reports, and design suggestions from players and developers are welcome to help guide upcoming feature expansions and balance patches.
